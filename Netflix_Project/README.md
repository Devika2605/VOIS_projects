
Netflix Dataset Analysis
Project for VOIS Internship / Personal Project

📖 Project Overview

Netflix, Inc., a global streaming service founded in 1997, has transformed the way audiences consume movies and TV shows. With a constantly expanding content library, understanding trends, distribution, and patterns in Netflix's offerings can provide insights into user preferences, content production, and ratings.

This project analyzes the Netflix Movies and TV Shows dataset to extract meaningful insights, identify trends in content type, release years, ratings, durations, and genres, and explore patterns affecting viewer engagement.

🎯 Objectives

This analysis aims to answer the following questions:
What is the distribution of movies vs TV shows?
Which year had the highest content releases?
Which genres are most common on Netflix?
How do ratings vary across different content types?
Are TV shows longer in duration than movies?
Which countries contribute most to Netflix content?
Is there a correlation between content duration and rating?
Who are the top directors by number of productions?

🧩 Tools & Libraries

Language: Python 3.x
Libraries: Pandas, NumPy, Matplotlib, Seaborn, Plotly (optional for interactivity)
Environment: Google Colab / Jupyter Notebook / Streamlit

🗂 Dataset

File: netflix_titles.csv
Source: Netflix Movies and TV Shows Dataset - Kaggle
Contents: Information on shows and movies including title, type, director, cast, country, release year, rating, duration, genre, and description

⚡ Key Features

Data Cleaning & Preprocessing
Exploratory Data Analysis (EDA)
Outlier Detection & Handling
Content Type, Year & Genre Analysis
Rating Distribution & Correlation Analysis
Visualizations: Countplots, Barplots, Scatterplots, Heatmaps
Interactive Streamlit Dashboard (optional)

📊 Key Insights

Content type distribution: Movies vs TV shows (Movies dominate ~55%)
Year-wise content release: Peak content release in recent years (2018–2021)
Genre distribution: Top genres include Drama, Comedies, Documentaries
Top contributing countries: United States and India lead in content production
Rating distribution: Most shows are TV-MA and PG-13 rated
Duration trends: Movies average ~90–120 min; TV shows vary by number of seasons
Correlation: Slight correlation between content duration and ratings
