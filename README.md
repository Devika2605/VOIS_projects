## 📖 Project Overview

This repository contains two data analysis projects exploring content trends, distribution, and insights using Python, Pandas, and visualization libraries:

1. **Netflix Dataset Analysis (Major Project)**  
   Analyzes Netflix movies and TV shows to understand content type distribution, release trends, ratings, genres, top directors, and more. Includes interactive visualizations and Streamlit dashboard for exploration.  

2. **Airbnb NYC Hotel Booking Analysis (Minor Project)**  
   Explores Airbnb listings in New York City to analyze property types, neighborhood trends, pricing patterns, reviews, and host performance. Provides insights into availability, ratings, and top hosts.

---

## 🧩 Tools & Libraries

- **Language**: Python 3.x  
- **Libraries**: Pandas, NumPy, Matplotlib, Seaborn, SciPy, scikit-learn, Plotly (optional), Streamlit  
- **Environment**: Google Colab / Jupyter Notebook / Local Python

## 🗂 Datasets

| Project | File | Source | Key Columns |
|--------|------|--------|-------------|
| Netflix | `netflix_titles.csv` | [Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows) | type, title, director, cast, country, release_year, rating, duration, listed_in |
| Airbnb | `Airbnb_Open_Data.xlsx` | New York City Open Data | property_type, neighborhood, price, host_info, reviews, availability |

---

## ⚡ Key Features & Insights

### Netflix (Major)
- Movies vs TV shows distribution (~55% movies)  
- Year-wise content release trends (peak 2018–2021)  
- Top genres: Drama, Comedy, Documentary  
- Top producing countries: USA & India  
- Ratings distribution (most TV-MA and PG-13)  
- Top directors by production count  
- Duration trends & correlation with ratings  
- Interactive visualizations with Streamlit  

### Airbnb (Minor)
- Most common property type: Entire home/apartment (~65%)  
- Neighborhood with highest listings: Manhattan  
- Highest average price: Manhattan ($250/night)  
- Construction year vs price trends  
- Top hosts by listing count  
- Verified hosts have slightly higher review ratings  
- Price positively correlates with service fee (r = 0.72)  
- Availability vs host listing count analysis
